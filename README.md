# To-Do List

A simple, lightweight, and responsive To-Do List web application built with HTML, CSS, and Vanilla JavaScript.

## Features
- **Task Management**: Add tasks with specific dates and times.
- **Input Validation**: Alerts if a task name is not entered.
- **Persistent Storage**: Saves tasks using browser `localStorage` so tasks remain after refresh.
- **Delete & Reset**: Delete individual tasks or reset the entire list.

## Technologies Used
- HTML5
- CSS3 (Grid layout)
- Vanilla JavaScript
